## UNI-PROGRAMMING OS :
#### In Uni-Programming Operating System, the OS can hold only a single program in main memory (RAM) for execution.

#### Drawback :  CPU Idleness

#### Examples : MS-DOS, Batch OS


Throughput
The number of Process/Program completed in given time T.
$$\text{Throughput} = \frac{\text{No. of Completed Processes}}{\text{Time (T)}}$$

***

> [!NOTE] Force-full De-alloction
> Forcing a program to leave the CPU during its execution.

## MULTI - PROGRAMMING OS :
#### In Multi-Programmed OS, the OS can hold multiple ready to run Programs in Main Memory (RAM).

#### Types of Multi Programming OS
1. Non Preemptive Multi Programming OS
2. Pre-emptive Multi Programming OS

---
#### Non Preemptive Multi Programming OS:
##### In Non Preemptive Multi Programming OS, OS can not force a program/process to leave the CPU In the middle of execution. but the Program/Process can release the CPU voluntarily on its own.

##### Reason to leave CPU : 1. Program Execution completed 2. Need to perform I/O/System Call.


> [!IMPORTANT] Drawback
> Starvation : Making other programs wait for CPU allocation.

##### Example : Window 3.0

***

#### Pre-emptive Multi Programmed OS:
##### In Pre-emptive Multi Programmed OS, OS can make a Program/Process leave the CPU In the middle of its execution for highest priority Program/Process.


> [!IMPORTANT] 
> Pre-emptive Multi Programmed OS solves **Starvation** Problem.

##### Examples : Windows 95, Windows 10, Windows 11, Linux, UNIX

---

> [!IMPORTANT] MODE SHIFTING
> Switching between user and kernal mode is called MODE SHIFTING.
> ![[os2.png]]
> In CPU a register known as *Process Status Word* holds *Mode Bit(0/1)*,  this Mode bit tells that are os executing in Kernal Mode or User Mode. 
> 0 for Kernal Mode, 1 for User Mode or vice versa 

> [!IMPORTANT] ## Reason for Mode Shifting
> #### SYSTEM CALL
> #### INTERRUPT
> #### EXCEPTION
> #### TRAP

### ARICHITECTURAL REQUIREMENTS TO IMPLEMENT MULTI PROGRAMMED OPERATING SYSTEM :
### 1. I/O Device / Secondary Storage Device / Disk :
#### I/O Device should be DMA [Direct Memory Access] Compatable.

> [!NOTE] DMA
> Direct Memory Access, or DMA is a computer feature that allows hardware like hard drive, sound card to send data straight to main memory (RAM). skipping CPU.
> 
### 2. RAM/Memory Unit :
#### Memory Unit can perform Address Translation.

![Address Translation.png](https://github.com/dolly2001/operating-system/blob/main/src/images/Address%20Translation.png)

> [!NOTE] Address Translation
> **Logical Address :** Address generated by the CPU during program/process execution.
> **MMU:** MMU or Memory Management Unit, is a computer hardware component responsible for translating logical address or virtual address to physical address.
> **Physical Address :** Address of a Program stored in main memory.

### 3. CPU/Processor : 
#### Must support *Dual Mode* operation.
![Dual Mode.png](https://github.com/dolly2001/operating-system/blob/main/src/images/Dual%20Mode.png)
